5. Placement

Glissez le logo (la forme verte) directement dans la vue 3D pour le positionner — les décalages ci-dessous suivent le geste et restent modifiables à la main pour un réglage au mm près.

6. Mode d'impression

Relief : le logo est un objet séparé posé sur la surface — robuste, fonctionne sur n'importe quel modèle.
Gravé : le logo est creusé dans le modèle, avec une pièce qui comble exactement le creux — nécessite un modèle étanche ("watertight").
